[ final String과 const String ]

final String 변수	//는 한 번만 값을 할당할 수 있어 이후에 변경 불가능, 런타임에 값이 결정됨
     혹은
const String ???	//위와 똑같이 컴파일 타임에 값이 결정되고,메모리 최적화에 동일한 const 값은 메모리에서 공유됨 
※ final과 const는 값이 변경되지 않도록 만드는 키워드
※ String 같은 객체 사용 시 >> 불변성 보장 및 성능 최적화에 도움이 됨

final의 경우 실행 중 결정되는 불변 값을 위해 사용되고, const는 미리 결정된 불변 값 및 최적화를 위해 쓰임




[ String과 String? 그리고 null safety쪽..? 연산자]

String? : nullable 타입 변수(= 문자열(String) 값을 가질 수도 있고, null 값을 가질 수 있는 타입의 변수)
※ String?를 쓰는 이유 : null을 담기 위해 사용_(일반적인 String에는 반드시 문자열 값을 넣어야 해서 null이 들어갈 수 없음 >> String일 때, null 사용 시 오류가 발생할 수 있어 뒤에 ?를 붙임)
※ dart에서는 null safety 지원해서 오류를 방지할려는 타입에 ?을 붙여 명시적으로 허용 가능함

- . : 맴버 접근 연산자
- ?. : 객체에서 속성이나 메서드에 접근 시 객체가 null일 수도 있을 때 안전하게 접근 가능(>> 객체가 null이면 전제 표현식이 null이 되어 오류 없이 넘어감)
- !. : !통해 null이 아님을 단언함_(특정 객체 값이 null일 경우 런타임 오류 발생(null 변수도 받음))
